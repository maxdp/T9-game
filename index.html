T9 Word Game

Is this word "good"? Add up neighboring digits until they read 1, 2, 3, 4… in order (wrapping around counts too).

How it works

Every letter has a T9 press-count — how many times you'd tap its key on an old phone keypad (A=1, B=2, C=3, D=1, E=2, F=3, …). A word is good if you can merge some of its neighboring digits (by adding them together) so the sequence counts up (1, 2, 3, 4, …) or counts down (…, 4, 3, 2, 1) with no gaps or repeats. The run is also allowed to wrap around — e.g. 4, 1, 2, 3 counts (1, 2, 3, 4 starting partway through), and so does 3, 2, 1, 4 (4, 3, 2, 1 starting partway through).
