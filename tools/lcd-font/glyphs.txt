// The phone screen's bitmap fonts, drawn in the style of mid-2000s Nokia
// phones. tools/lcd-font/build.py turns this into the font files the page
// lays its text out with (testing/fonts/) and the bitmaps the LCD renderer
// draws (testing/js/lcd-font.js), so both always agree.
//
// "font NAME ascent=A descent=D space=S" starts a font: A rows above the
// baseline, D below, and a space S pixels wide. Each glyph is "= C" (the
// character) followed by its rows from the top ("#" lit, "." dark);
// missing rows at the bottom are blank. Every glyph gets one pixel of
// spacing after it.
